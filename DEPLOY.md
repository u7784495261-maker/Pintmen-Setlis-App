# Deploying The Pintmen Songbook

This version is intentionally flat so it can be uploaded easily from a phone. All required website files are in the repository root.

## GitHub Pages
1. Upload all files in this folder to the repository root.
2. GitHub → Settings → Pages.
3. Under Build and deployment choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.

No database, accounts or backend are required. Changes made in Edit mode are stored on the device. The original The Pintmen Reloaded setlist remains in the app.
