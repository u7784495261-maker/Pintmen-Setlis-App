# The Pintmen Songbook

A standalone, mobile-first offline PWA for The Pintmen.

- Original 39-song The Pintmen Reloaded setlist included
- Multiple setlists
- Shared song library
- Lyrics
- Gig Mode
- Swipe / previous / next
- Auto-scroll
- Wake lock
- Search
- Local editing
- Import/export
- Offline support
- Installable PWA

There is deliberately no shared database or account system. Edit changes are saved locally on the device.
